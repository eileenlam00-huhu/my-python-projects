# 🖨 打印机状态监控机器人

通过飞书机器人自动监控打印机状态，写入飞书表格，异常时通知负责人。

## 功能

- 批量查询打印机状态（支持 Klipper/Moonraker 协议）
- 查询结果自动写入飞书表格（每次新增一列，保留历史）
- 异常/离线/暂停时自动通知负责人
- 支持多用户隔离（每人管理自己的表格）
- 支持多表格配置
- 支持自定义定时任务
- 飞书长连接模式（内网可用，无需公网地址）

## 文件说明

```
printer_bot/
├── bot_server.py         # 机器人主服务（飞书长连接 + 消息处理 + 定时任务）
├── printer_monitor.py    # 打印机监控核心（查询 + 写表格 + 发通知）
├── bot_config.json       # 运行时配置（自动生成，按用户存储）
├── requirements_bot.txt  # Python 依赖
└── README.md             # 本文件
```

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements_bot.txt
```

### 2. 配置飞书应用

在 `bot_config.json` 中填入飞书应用凭证：

```json
{
  "feishu_app_id": "你的App ID",
  "feishu_app_secret": "你的App Secret",
  "users": {}
}
```

### 3. 飞书开放平台设置

| 步骤 | 操作 |
|------|------|
| 开启机器人 | 应用能力 → 机器人 → 开启 |
| 事件方式 | 事件与回调 → 选择「使用长连接接收事件」 |
| 添加事件 | `im.message.receive_v1` |
| 开通权限 | 见下方权限列表 |
| 知识库授权 | 把应用添加为知识库/文档的协作者（可编辑） |
| 发布版本 | 创建版本 → 发布 |

### 4. 启动服务

```bash
python bot_server.py
```

### 5. 在飞书中使用

搜索你的机器人名称，开始对话：

```
添加表格 https://xxx.feishu.cn/wiki/xxxxx F022+NANO
查询
设置时间 09:00,14:00,18:00
```

## 机器人命令

| 命令 | 说明 |
|------|------|
| `查询` | 执行你的全部表格监控 |
| `查询 1` | 只执行第1个表格 |
| `状态` | 查看你的配置 |
| `帮助` | 显示使用说明 |
| `添加表格 <URL> <子表名>` | 添加一个表格 |
| `删除表格 <编号>` | 删除指定表格 |
| `设置时间 HH:MM,HH:MM` | 设置定时执行 |
| `查看定时` | 查看当前定时任务 |
| `删除定时` | 清除所有定时任务 |

## 表格格式要求

从第2行开始填写打印机信息（第1行为表头）：

| 列 | 内容 | 说明 |
|----|------|------|
| A | 设备名称 | 如 NANO-212.39 |
| B | IP地址 | 如 172.23.212.39 |
| C | 型号 | 如 I7 NANO |
| D | 负责人 | 如 林惠玲 |
| E | 负责人邮箱 | 如 lin@company.com（用于异常通知） |
| F列起 | 自动写入 | 每次查询自动新增一列，写入状态 |

## 所需飞书权限

| 权限标识 | 用途 |
|---------|------|
| `wiki:wiki:readonly` | 从知识库获取表格信息 |
| `sheets:spreadsheet` | 读写电子表格 |
| `contact:user.email:readonly` | 通过邮箱查找用户（发通知） |
| `im:message:send_as_bot` | 机器人发送消息 |
| `im:message:receive_as_bot` | 机器人接收消息 |

## 多用户说明

- 每个用户的表格配置互相隔离
- 用户A添加的表格，只有A能查询和触发
- 定时任务按用户独立运行，结果只通知对应用户
- 配置自动保存到 `bot_config.json`

## 注意事项

- 打印机需支持 Klipper/Moonraker API（端口 4408）
- 飞书表格需要把应用添加为协作者（可编辑权限）
- 首次使用需要在飞书中搜索机器人并开启对话
- 通知功能需要负责人邮箱正确且已注册飞书
